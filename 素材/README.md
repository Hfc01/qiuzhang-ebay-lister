# 数字酋长批量刊登工具

通过 Playwright CDP 接管本地调试 Chrome，在「数字酋长 ERP」网页版上自动完成 eBay 商品复制刊登的辅助工具。

## 功能

- **批量复制刊登**：将 1 个商品复制成多份，逐行填入不同的 AI 生成标题和图片，铺到多个 eBay 账号
- **标题自动填充**：读取 `素材/<产品名>/标题.txt`（1 行=全部共用，10 行=逐行使用）
- **图片自动上传**：读取 `素材/<产品名>/图片/`，逐行注入并自动拖到第一位，点「确定」保存
- **监控台**：浏览器 Dashboard，自动读取在线 Listing 列表供点选，实时显示进度和日志
- **安全机制**：工具永不点击「开始刊登」按钮，最后一步由人工确认

## 使用方法（Windows）

1. 双击 `启动调试浏览器.bat`（自动查找 Chrome/Edge，独立 profile）
2. 在该浏览器中登录数字酋长，打开刊登页面
3. 双击 `启动监控台.bat`，在浏览器打开的 Dashboard 中选择产品素材和目标 Listing
4. 点击开始后程序自动执行，**刊登按钮仍需人工点击**

首次使用需先安装依赖：`npm install`（或直接使用分发版 zip，内含便携 Node 与依赖）。

## 停止运行

双击 `停止运行.bat`：按 PID 精确停止监控台服务，再关闭调试浏览器。

## 目录说明

```
flow.mjs        核心流程引擎（JExcel 填值、图片上传、拖拽排序）
server.mjs      监控台本地服务（端口 8899）
dashboard.html  监控台页面
素材/<产品名>/   标题.txt + 图片/（存放规范见 素材/AI素材生成指南.md）
```

## 安全提示

`tmp/chrome-debug/` 保存了浏览器登录态，已在 `.gitignore` 中排除，**切勿提交到仓库或分发给他人**。
