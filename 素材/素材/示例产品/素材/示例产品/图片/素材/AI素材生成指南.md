# AI 素材存放规范（给 AI 助手）

> 用户会自己提供标题和生图提示词，AI 只负责把产出物**存放到正确位置**。
> **路径是相对的**：本工具可以解压到任何盘符任何目录，一切以「工具根目录」为基准（就是本文件的上级目录，即 `素材\` 所在的文件夹）。AI 应先确认工具实际所在位置，再拼路径，**禁止假设 D 盘或任何固定盘符**。

## 存放位置与结构

```
<工具根目录>\素材\<产品名>\
├── 标题.txt     ← 标题文本，一行一个（UTF-8，不编号、不留空行）
└── 图片\        ← 01.png、02.png … 10.png（按序号命名）
```

## 存放规则

1. **文件夹名**：用用户提供的产品名；过滤 Windows 非法字符 `\ / : * ? " < > |`
2. **数量校验**（存完必须核对并回报）：
   - 标题：10 行（每行不同）或 1 行（十行共用），其他数量会报错
   - 图片：10 张（每行一张）或 1 张（十行共用）
3. **图片命名**：按顺序重命名为 `01.png ~ 10.png`（上传顺序即文件名顺序）；ImageGen 生成的默认长文件名必须改名
4. **10 行标题的第 N 行 = 表格第 N 行**，顺序有讲究时提醒用户确认顺序
5. 生成的图片、标题直接落入对应产品文件夹，不要存到别处再挪

## 禁止事项

- 禁止假设工具在 D 盘或任何固定路径——先定位工具根目录再操作（服务运行时可用 http://127.0.0.1:8899/api/status 或监控台确认）
- 禁止改动其他产品文件夹
- 禁止点击 eBay/数字酋长页面的提交类按钮
