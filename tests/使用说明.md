# 数字酋长批量刊登工具 · 使用说明

> 把 1 个商品复制成 10 份、铺 10 个 eBay 账号、换 AI 标题和图片，全程自动，最后人工确认上架。
> 原来手工约 30 分钟，现在约 3 分钟。

---

## 一、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| 浏览器 | Chrome 或 Edge（启动脚本会自动查找，无需手动配置路径；两个都没有才需要安装一个） |
| Node.js | **不需要安装**（工具自带 `runtime\node.exe` 便携版） |
| 数字酋长账号 | 需要能登录 erp.datacaciques.com 并使用刊登功能 |

## 二、首次使用（只需做一次）

1. 把整个文件夹解压到**任意位置**（D 盘、E 盘都行，路径不要有奇怪的特殊字符即可）
2. 双击 `启动调试浏览器.bat` —— 会弹出一个独立的 Chrome 窗口并打开数字酋长
3. 在这个 Chrome 里**登录你的数字酋长账号**（登录态会保存在本文件夹 `tmp\chrome-debug`，以后每次打开都是登录好的，不用重复登录）
4. 双击 `启动监控台.bat` —— 浏览器会自动打开监控页（127.0.0.1:8899）

## 三、每次刊登的流程

1. 确保「调试 Chrome」开着，并停在数字酋长「在线 Listing」页
2. 在监控页点「↻ 刷新列表」→ 会自动读出所有在线商品
3. 在列表里**点选一条**要复制的商品
4. 在「产品素材」下拉框选一套素材（标题 + 图片）
5. 点「▶ 开始执行」→ 按提示点两次「确认继续」
6. 工具自动完成：复制 → 填 10 行 → 选 10 个账号 → 写标题 → 逐行传图并置顶
7. 跑完后**你自己在数字酋长页面核对**，确认无误后**自己点「开始刊登」**

> ⚠️ 工具永远不会替你点「开始刊登」——最后上架这一下永远由人完成。

## 四、准备素材（每个产品一个文件夹）

```
素材\
└── 我的产品A\            ← 文件夹名随意（产品名）
    ├── 标题.txt          ← 10 个标题，一行一个；只放 1 个则十行共用
    └── 图片\             ← 10 张图，命名为 01.png ~ 10.png；只放 1 张则十行共用
```

规则详见 `素材\AI素材生成指南.md`。

## 五、停止运行

用完想彻底关掉后台？双击 **`停止运行.bat`**，一键做两件事：
1. 停止监控服务（精确识别，不会误杀电脑上其他程序）
2. 关闭调试 Chrome（只关本工具启动的那个，不动你的日常浏览器）

登录态会保留，下次「启动调试浏览器.bat」打开仍是登录好的。

> 不想用 bat 也行：关掉监控台的黑窗口 = 停止服务；直接关调试 Chrome 窗口 = 关浏览器。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 提示「连接失败」 | 先双击「启动调试浏览器.bat」，确认 Chrome 窗口开着 |
| 提示「没有找到 eBay 页面」 | 调试 Chrome 里没停在数字酋长页面，切回去打开 |
| 提示「请先关闭编辑器」 | 上一次的 Copy Listing 编辑弹窗还开着，先点 × 关掉 |
| 提示没找到 Chrome | 编辑「启动调试浏览器.bat」，把 CHROME 改成你的 chrome.exe 完整路径 |
| 提示没找到 Node | 确认 `runtime\node.exe` 还在工具文件夹里（别单独删它） |
| 某一行失败 | 监控台日志会写明第几行哪个环节失败；修正后重新跑一轮即可 |

## 七、安全说明

- 登录态只存在你本机 `tmp\chrome-debug` 文件夹，不上传任何服务器
- 工具只操作「复制出来的草稿」，不修改你的在线商品
- 所有「保存/提交」类动作（开始刊登）均由人工点击
